# Richemont — Data-Layer Prep for Lillian (Second Interview)

Purpose: give Lillian a concrete layer or two below the word *data* when she meets
Richemont, so a claim about "data transformation" is grounded in the counts, systems,
and rules that actually make Richemont hard.

Scope of this repo:

- `sap-landscape.md` — the ~120-instance SAP estate, the "Gemini" template, non-SAP satellites, and the New Foundations Bluefield programme.
- `acquisition-erp-heritage.md` — the acquisition stream and which Maisons are on Gemini, still off it, or being carved out.
- `sku-and-article-master.md` — reference counts, uniqueness patterns, movement BOM depth.
- `manufacturing-and-supply-chain.md` — Manufacture vs. outsourced status by Maison, Group-owned component makers, boutique network.
- `regulatory-data-rules.md` — Kimberley, ESPR/DPP, Swiss Made 60% rule, hallmarking, LkSG/CS3D, CITES, GDPR/PIPL/CCPA.

See `SYNTHESIS.md` for the inline briefing given to Lillian.
